## Evidence and supporting libraries

Every tile is selected from direct repository dependencies, observed source languages, or the pinned source evidence in `data/skill-source-evidence.json`. The showcase does not infer skills from repository topics or generic concepts. `data/skills-catalog.json` records direct names and each supporting library explicitly; the complete dependency inventory remains in `data/technologies.json` and `docs/TECHNOLOGIES.md`.

Small framework helpers are listed under their actual evidence context: React components, Express middleware, TypeScript tooling, Tailwind utilities, and npm packages. This records their presence without presenting each helper as an independent proficiency claim. The local `backend` workspace package is excluded.
